# Настройки ChunkWorld (ScriptableObject)

| Asset | Назначение |
|-------|------------|
| **DefaultBiomeTextures.asset** | Каталог спрайтов пола по биомам (менять в Inspector) |
| **DefaultChunkWorldConfig.asset** | Ссылка на каталог + параметры стриминга |

Создание: **Tools → ChunkWorld → Create Default Settings Assets**  
Обновить спрайты из папок `Textures/*`: **Tools → ChunkWorld → Refresh Biome Textures From Folders**

Вручную: **Create → ChunkWorld → Biome Texture Catalog** или **Chunk World Config**.
