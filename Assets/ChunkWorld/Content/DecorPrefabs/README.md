# Объекты на чанках (декор)

Prefab элементов, которые **расставляются поверх** основы чанка: камни, кусты, пни, валуны.

Не путать с врагами и снарядами — они **не** должны быть дочерними к чанку.

Наборы можно менять при прокачке графики в игре (отдельный слой TankSurvivor → вызов API ChunkWorld).
