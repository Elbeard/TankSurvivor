# Текстуры основы чанков

PNG в подпапках по биому. Импорт Unity: **Sprite (2D)**.

| Папка | Биом |
|-------|------|
| `Grass/` | трава |
| `Send/` | песок (Sand) |
| `Stone/` | скала |
| `Taiga/` | тайга |

**Реестр для игры** — не код, а asset:  
`Content/Settings/DefaultBiomeTextures.asset`  
Создать/обновить: **Tools → ChunkWorld → Create Default Settings Assets** или **Refresh Biome Textures From Folders**.

PSD храните у себя; сюда — **экспорт PNG**.
