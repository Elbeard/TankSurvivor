# Кириллица в поле чата Cursor (Windows, 3.4)

## Главное

В Cursor **два разных микрофона**:

| Микрофон | Где | Русская кириллица |
|--------|-----|-------------------|
| **Встроенный** (Agents, `Ctrl+M`, иконка в чате) | Окно Agents | Часто **нет** — текст уходит в **английский** (облачное STT) |
| **VS Code Speech** (расширение) | Команды Voice / Chat | **Да** — при `speechLanguage: ru-RU` |
| **Windows** `Win+H` | Любое поле ввода | **Да** — если в системе русский |

Правила AI (**отвечать по-русски**) **не меняют** язык распознавания встроенного микрофона.

---

## Способ 1 — Windows `Win + H`

### Важно: Windows 10 и русский

На **Windows 10** (в т.ч. 22H2) голосовой ввод **`Win + H` официально не поддерживает русский** — только английский, китайский, французский, немецкий, итальянский, португальский (Бразилия), испанский и др. **без Russian**.

Сообщение *«русский язык недоступен»* — **ожидаемо** на Windows 10, это не лечится полной установкой языкового пакета.

| Система | `Win + H` + русский |
|---------|---------------------|
| **Windows 10** | ❌ Не поддерживается Microsoft |
| **Windows 11** | ✅ Russian в списке языков voice typing |

**Что можно сделать на Windows 10:** см. способы 2–4 ниже (VS Code Speech, клавиатура, браузер).

### Если у вас Windows 11

1. **Параметры → Время и язык → Язык и регион** → **Русский** → **⋯** → **Параметры языка**.
2. Скачайте **Распознавание речи** / **Speech** (если есть в списке).
3. **Параметры → Конфиденциальность → Речь** — включите **онлайн-распознавание речи**.
4. В поле чата: раскладка **РУС** → **`Win + H`** → говорите.

### Микрофон Windows

**Параметры → Конфиденциальность → Микрофон** — доступ для приложений и для **Cursor**.

## Способ 2 — расширение VS Code Speech (лучший вариант на Windows 10)

Локальное распознавание, в т.ч. **ru-RU**. Подходит, если встроенный микрофон Agents только на английском.

### Установка

1. **`Ctrl + Shift + X`** (Extensions).
2. Поиск: **`VS Code Speech`** (издатель **Microsoft**, id: `ms-vscode.vscode-speech`).
3. **Install**.
4. При первом запуске голоса — установите **языковой пакет речи** для русского, если предложит.

### Настройка (уже добавлено в User settings)

```json
"accessibility.voice.speechLanguage": "ru-RU"
```

Файл: `%APPDATA%\Cursor\User\settings.json`

Перезагрузите окно: **`Ctrl + Shift + P`** → **Developer: Reload Window**.

### Как говорить в чат

Попробуйте по очереди (**`Ctrl + Shift + P`** → введите команду):

| Команда | Назначение |
|---------|------------|
| **Chat: Voice Chat in Chat View** | Голос в панели Chat |
| **Chat: Start Voice Chat** | `Ctrl + I` — голосовой чат |
| **Voice: Start Dictation in Editor** | `Ctrl + Alt + V` — диктовка в редакторе |

Для окна **Agents** расширение может работать иначе; если кириллицы нет — оставайтесь на **`Win + H`** в поле Agents.

## Способ 3 — встроенный микрофон Cursor (часто только English)

Если в **Cursor Settings → voice** нет **Russian** / **ru-RU** — встроенный микрофон **не умеет** кириллицу. Это не ошибка настроек, а ограничение функции.

Что проверить на всякий случай:

1. **Cursor Settings** → `voice` → **Input language = Russian** (если пункт есть).
2. При записи — переключатель **RU**, не **EN**.
3. Перезапуск Cursor.

---

## Способ 4 — голос в браузере (без установки)

1. Откройте [Google Docs](https://docs.google.com) или поиск Google.
2. Переключите интерфейс/ввод на **русский**, включите **голосовой ввод** (микрофон в Chrome/Edge).
3. Надиктуйте текст → **скопируйте** → вставьте в поле чата Cursor.

Работает, если в браузере русский голосовой ввод доступен (зависит от аккаунта и региона).

## Способ 5 — обновление до Windows 11

Если нужен именно **`Win + H` на русском** в любых приложениях — в [списке Microsoft](https://support.microsoft.com/windows/use-voice-typing-to-talk-instead-of-type-on-your-pc) **Russian** указан для **Windows 11**, не для Windows 10.
