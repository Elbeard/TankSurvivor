# Игровой цикл

## Целевой цикл (видение)

```
[Старт забега] — базовая графика / тихий звук (tier 0)
        │
        ▼
┌───────────────────┐
│  Бой на арене     │◄────┐
│  движение, огонь  │     │
│  враги с КРАЁВ    │     │
└─────────┬─────────┘     │
          │               │
          ▼               │
   Убийства, время        │
          │               │
          ▼               │
   + Score                │
          │               │
          ├─► (опционально) волна усилилась
          │
          ▼
   ┌─────────────┐
   │  Магазин    │  тратим Score:
   │  (пауза /   │  • Visual tier
   │   Tab)      │  • Audio tier
   └──────┬──────┘  • (опц.) статы
          │
          ▼
   Применить тир → заметнее VFX, спрайты, музыка
          │
          └───────────────────┘
          
   HP = 0 → Game Over (итоговый score, рекорд)
```

## Края карты (два слоя)

1. **Сейчас (ближайший шаг):** враги **спавнятся у границ** фиксированной арены — игрок чувствует угрозу «с краёв».
2. **Позже:** при подходе к границе **подгружаются чанки** тайлов — карта растёт наружу (см. [implementation-plan.md](implementation-plan.md), Phase 5).

## Текущий MVP (что есть в Play Mode)

```
Старт Scene_1
  → движение, башня, стрельба, звук выстрела
  → враг может преследовать
  → снаряд без урона (коллизия отключена)
  → score / магазин / края — пока нет
```

## Пример сессии на 3 минуты (когда vision реализован)

| Время | Событие |
|-------|---------|
| 0:00 | Tier 0: простые спрайты, минимум музыки |
| 0:30 | Первая волна с северного края; +score за убийства |
| 1:00 | Игрок покупает **Visual tier 1** — вспышка выстрела, след снаряда |
| 1:30 | Давление с двух краёв; score растёт |
| 2:00 | Покупка **Audio tier 1** — включается полноценный трек |
| 2:30 | Visual tier 2 — лучше взрывы / тайлы |
| 3:00 | HP = 0 или игрок сбежал — экран с итоговым score |

## Параметры (текущие в коде)

| Параметр | Где |
|----------|-----|
| Скорость танка | `PlayerMovement._movingSpeed` |
| Скорострельность | `TankGun.fireRate` |
| Скорость снаряда | `TankGun.projectileSpeed` |
| Радиус агро | `EnemyAwarenessController._playerAwarenessDistance` |
| Lifetime снаряда | `Projectile.lifetime` |
